Role: You are an Expert Full-Stack ML Engineer.
Task: Build and maintain a production-ready Handwritten Character Recognition (A-Z, 0-9) web application and Multi-Page Document OCR Engine.

Technical Specifications & Current Architecture:

1. Backend (Flask, TensorFlow, OpenCV, Generative AI):

main.py: A Flask server with CORS enabled. 
- /predict POST route: Accepts a Base64 drawing. Preprocesses it by extracting the ink bounding box, centering it on a square canvas to preserve the aspect ratio, resizing it to 20x20, and padding it to 28x28 (white on black, normalized to [0,1]). It loads `character_model_tf210.h5` and uses the EMNIST Balanced mapping (47 classes) to return the character and confidence score.
- /ocr POST route: Handles multi-page PDF documents and images. Batches multiple pages into a single API request using Google's `gemini-2.5-flash` to bypass rate limits (15 RPM). Implements graceful offline fallbacks including Ollama local LLM (`qwen2.5vl:7b`), EasyOCR, TrOCR, and Tesseract.

2. Model Training (model_trainer.py) & Dataset:

- Dataset Handling: The app now operates 100% offline using a locally exported `dataset/emnist_balanced.npz` (avoiding the broken `emnist` library download).
- The EMNIST Flip: REMOVED. The current dataset is natively oriented correctly. Applying manual rotations breaks the model.
- CNN Architecture: Conv2D (32 filters, 3x3, ReLU) -> MaxPooling2D -> Conv2D (64 filters, 3x3, ReLU) -> MaxPooling2D -> Flatten -> Dense (128, ReLU) -> Dropout (0.5) -> Dense (47, Softmax).
- Saved as `character_model_tf210.h5`.

3. Frontend (Modern UI - HTML/JS/CSS):

templates/index.html: Clean, centered, dark-themed UI. Features a 300x300 HTML5 Canvas, a "Clear" button, and a "Predict" button. Includes sections for displaying both the Character Prediction and the Document OCR results.
static/css/style.css: Modern styling with glowing canvas interactions.
static/js/script.js: Implements smooth drawing logic handling both mouse and touch events. Crucial: Set ctx.lineWidth = 15 and ctx.lineCap = 'round'.
